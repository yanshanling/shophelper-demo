# Shophelper 演示版

跨境电商智能客服 Agent · 运营管理后台（面试演示版）。

**单文件、零依赖、离线可用**：双击 `index.html` 即可打开完整的管理后台演示，数据存于浏览器本地（localStorage），可随时一键重置。也可直接访问 GitHub Pages 在线演示。

## 演示什么

**v2.0 飞轮闭环版**：在 v1.0「配置外置」的基础上，补齐数据飞轮的 4 处断链——看得见线上对话（日志）、坏例回得去资产层（标注回流）、改配置测得了回归（测评集）、意图关键词配置化（意图管理）。

### 九个功能模块

| 模块 | 演示要点 |
|---|---|
| 📊 概览仪表盘 | 配置资产统计、意图分布、知识库命中 TOP、飞轮指标（今日会话 / 待标注 / 测评通过率） |
| 🎯 意图管理 | 意图关键词 / 权重 / 启停**配置化**，引擎实时读取配置打分，改关键词无需发版；意图级测试 |
| 📚 知识库管理 | 分类 + 中英双语条目 CRUD、发布/草稿/停用状态、**检索测试**（模拟 Agent 端命中） |
| 📝 Prompt 管理 | 人设与场景话术编辑、变量占位符、**版本快照 + 一键回滚**、渲染预览 |
| 🤖 大模型接入 | OpenAI 兼容协议、供应商/Key/参数、**按语言路由**（英文线/中文线/兜底）、连通性测试 |
| 📋 对话日志 | 测试台对话自动入库（意图 / 置信度 / 安全等级 / Trace 回放）、按意图与标注状态筛选 |
| 🏷️ 标注回流 | 待标注队列、坏例三分类（意图误判 / 知识未命中 / 回复差）、一键回流资产层 |
| 🧪 测评集管理 | 分层用例（意图 / 安全红线 / 端到端）、**一键回归**防退化、用例增删 |
| 🧪 Agent 测试台 | 实时对话 + **ReAct Trace 逐步回放** + 配置溯源（命中哪条知识库/触发哪级安全策略） |

### 推荐演示路径（约 5 分钟）

**v1.0 配置驱动闭环：**

1. 打开 **Agent 测试台** → 点「🇨🇳 加急配送」发送 → 看回复与右侧 Trace
2. 去 **知识库管理** → 编辑「加急配送说明」→ 把运费改成 $9.99
3. 回 **测试台** 再问同样的问题 → 回复立即变化（配置驱动闭环）

**v2.0 飞轮闭环：**

4. **意图管理** → 关闭 CHITCHAT 意图 → 回测试台发「你好」→ 识别为 FAQ（配置实时生效）
5. **对话日志** → 看刚才的会话已入库，点开详情回放 Trace
6. **标注回流** → 标注一条坏例「意图误判」→ 关键词自动补进意图配置
7. **测评集** → 一键回归 → 全绿（改配置后无退化）
8. 发送「🔴 法律风险」→ 看四级安全护栏自动升级人工

## 技术说明

- 单文件 HTML：内嵌种子数据 + Agent 引擎（JS 版），双击即开，可发布 GitHub Pages
- Agent 引擎：**配置驱动**的意图加权打分（读取 `DB.intents`，score = 命中数 × 权重 + 知识库 FAQ 动态加分）、四级安全护栏（低/中/高/极高 → 自动回复 / 人工审核 / 强制升级）、ReAct Trace
- 数据持久化：localStorage（v2 数据版本），右上角可重置演示数据
- 模型调用：演示版仅做配置管理（Key/参数/路由），不真实调用 API；生产版为 React + AntD + FastAPI 前后端分离架构，接口层已预留 LLM 调用位置

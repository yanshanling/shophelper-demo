# Shophelper 演示版

跨境电商智能客服 Agent · 运营管理后台（面试演示版）。

**单文件、零依赖、离线可用**：双击 `index.html` 即可打开完整的管理后台演示，数据存于浏览器本地（localStorage），可随时一键重置。也可直接访问 GitHub Pages 在线演示。

## 演示什么

解决"Agent 配置硬编码在代码里，运营改不动"的问题——把**知识库、Prompt、大模型配置**全部外置为可视化配置，运营在后台增删改查，Agent 运行时实时读取，**改一条 FAQ 无需发版**。

### 五个功能模块

| 模块 | 演示要点 |
|---|---|
| 📊 概览仪表盘 | 配置资产统计、意图分布、知识库命中 TOP、配置变更审计时间线 |
| 📚 知识库管理 | 分类 + 中英双语条目 CRUD、发布/草稿/停用状态、**检索测试**（模拟 Agent 端命中） |
| 📝 Prompt 管理 | 人设与场景话术编辑、变量占位符、**版本快照 + 一键回滚**、渲染预览 |
| 🤖 大模型接入 | OpenAI 兼容协议、供应商/Key/参数、**按语言路由**（英文线/中文线/兜底）、连通性测试 |
| 🧪 Agent 测试台 | 实时对话 + **ReAct Trace 逐步回放** + 配置溯源（命中哪条知识库/触发哪级安全策略） |

### 推荐演示路径（约 3 分钟）

1. 打开 **Agent 测试台** → 点「🇨🇳 加急配送」发送 → 看回复与右侧 Trace
2. 去 **知识库管理** → 编辑「加急配送说明」→ 把运费改成 $9.99
3. 回 **测试台** 再问同样的问题 → 回复立即变化（配置驱动闭环）
4. 发送「🇨🇳 投诉场景」「🔴 法律风险」→ 看四级安全护栏自动升级人工
5. 去 **Prompt 管理** → 看版本历史与回滚；**大模型接入** → 看多线路路由与连通性测试

## 技术说明

- 单文件 HTML：内嵌种子数据 + Agent 引擎（JS 版），双击即开，可发布 GitHub Pages
- Agent 引擎：意图加权打分（动作意图优先于语境信号）、四级安全护栏（低/中/高/极高 → 自动回复 / 人工审核 / 强制升级）、ReAct Trace
- 数据持久化：localStorage，右上角可重置演示数据
- 模型调用：演示版仅做配置管理（Key/参数/路由），不真实调用 API；生产版为 React + AntD + FastAPI 前后端分离架构，接口层已预留 LLM 调用位置
